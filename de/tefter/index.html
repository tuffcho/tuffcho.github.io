Tefter

Verwalte deine persönlichen Finanzen — komplett offline.

Erfasse und organisiere deine persönlichen Finanzen. Alle Daten bleiben auf deinem Telefon — ohne Konto, ohne Werbung, ohne Internet. Die kostenlose Version bietet die Grundfunktionen, die kostenpflichtige Version erweiterte Funktionen.

Funktionen

  • Komplett offline — deine Daten verlassen dein Telefon nie
  • Keine Werbung
  • Kostenlose Version mit Grundfunktionen
  • Kostenpflichtige Version mit erweiterten Funktionen
